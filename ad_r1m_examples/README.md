# AD-R1M Examples

A collection of example applications that build on top of the AD-R1M software stack.
Each example is self-contained in its own subfolder with its own README, launch files,
configs, and scripts.

## Examples

| Folder | Description |
|--------|-------------|
| [lift_waypoint_demo](lift_waypoint_demo/) | Waypoint following with Nav2 and lift/elevator hardware add-on |
| [imu_hil_demo](imu_hil_demo/) | Control simulated robot yaw with a real IMU (hardware-in-the-loop) |
